# twine-campus-life-the-case-of-the-missing-locket

Feedback Recieved
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
This is a genuinely impressive Distinction Level, ambitious submission that stands out as one of the most technically sophisticated projects in the cohort. Campus Life: The Case of the Missing Locket is a substantial, polished and inventive interactive narrative, exploring the More Human Than Human theme through a three-phase stealth adventure, personalised player character, distinctive cast, fourth-wall-breaking humour and engaging narrative design. The Twine implementation is exceptional, comprising 175 passages, over 11,000 words, a live countdown timer, randomised password system, persistent state variables, dynamic layouts and sophisticated custom CSS and Harlowe macros. These features demonstrate considerable programming ambition, technical confidence and creativity. The portfolio documentation is equally strong, with comprehensive research, detailed GDD content, exemplary feedback records, version control, risk assessment and a mature professional reflection. The transparent and detailed declaration of AI tool usage is particularly commendable, demonstrating professional integrity and an understanding of responsible practice.

Areas for improvement include making the world-building more specifically relevant to the game's setting and narrative, and improving the signposting and fairness of negative pathways, which can sometimes feel maze-like or punitive rather than offering meaningful consequences. Some of the narrator's inside jokes may also be less accessible to players unfamiliar with the student's creative style. The unresolved external image-rendering issue is a notable technical weakness affecting the final player experience, although the inclusion of images in the portfolio partially mitigates this. The submission format also does not meet the specified HTML export requirement, and the project timeline could provide greater detail.

Overall, this is an outstandingly ambitious and well-documented project, demonstrating exceptional technical skill, creative thinking, professional awareness and a sophisticated understanding of interactive narrative design.
